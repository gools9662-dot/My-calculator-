হিসাব ক্যালকুলেটর – PWA প্যাকেজ

1) netlify.com এ ফ্রি অ্যাকাউন্ট খুলুন।
2) "Add new site" -> "Deploy manually" এ এই ফোল্ডারটা (zip খুলে) ড্র্যাগ করে ছেড়ে দিন।
3) যে লিংক পাবেন সেটা ফোনের Chrome এ খুলুন।
4) Chrome এর মেনু (তিন ডট) -> "Add to Home screen" বা "Install app" চাপুন।
   আইফোনে Safari -> Share -> "Add to Home Screen"।
এরপর নেট ছাড়াই অ্যাপ চলবে। প্রথমবার একবার নেট লাগবে।
